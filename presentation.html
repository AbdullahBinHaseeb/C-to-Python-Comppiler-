1. What is a Transpiler?

A normal compiler: Translates human code (like C++) into machine code (1s and 0s) so the computer can run it.


A transpiler (Our Project): Translates one human language into another human language.


Think of it like Google Translate. Instead of translating English to Spanish, our project translates C++ code into Python code.

2. Why Convert C++ to Python?

The Problem with C++

  • It has strict, difficult syntax.
  • You have to declare data types (int, float, string) for everything.
  • It takes a lot of lines of code to do simple tasks.

The Power of Python

  • Very easy to read and understand.
  • Great for modern technologies like AI and Data Science.
  • Does not require strict data types.

3. Our Web Interface

We built a beautiful website where users can type C++ on the left, and instantly get Python on the right.

4. How Does It Work & APIs Used

Our project operates on a Client-Server architecture powered by three specific APIs:


1. The Frontend (Client)

  • Fetch API: Acts as the network messenger that carries the C++ code from the website to the server.
  • DOM API: Interacts with the browser to instantly update the screen with the final Python translation.

2. The Backend (Server)

  • Custom REST API: Built with Python and Flask, it receives the data, translates it, and returns the result.

5. Step 1: The Frontend Website

  • Built with: HTML, CSS (Tailwind), and JavaScript.
  • How it works: When the user clicks the "Convert" button, a JavaScript feature called an API Fetch packages the code.
  • The Delivery: It acts like a messenger, carrying the C++ code across the internet to our backend server.

6. Step 2: The Backend Server

  • Built with: Python and the Flask Framework.
  • How it works: The server is always listening. When it receives the message from the frontend, it runs our "Lexical Engine".
  • What it does: It finds C++ rules and replaces them with Python rules, then sends the answer back to the user's screen.

8. The Hardest Part: Indentation

The Curly Brace Problem

In C++, we use curly braces { } to group code together inside loops or functions.


Python does not use braces. It relies strictly on empty spaces (indentation) to know which code belongs together.


Our Solution: Our backend server mathematically counts every time a { opens and a } closes. It uses that math to add the exact right amount of blank spaces in the final Python text.
